## 📝 Описание проекта

Веб-сайт, посвященный известным и влиятельным женщинам из разных сфер деятельности. 
Проект разработан на Django и демонстрирует применение ключевых концепций фреймворка, изученных в ходе курса.

## 🚀 Основные функции
- **Каталог известных женщин** с подробной информацией о каждой
- **Разделение статей по категориям** для удобной навигации
- **Возможность добавления статьи с помощью форм** с интуитивным интерфейсом
- **Админ-панель** для управления контентом
- **Система тегов** для удобной навигации
- **Пагинация** списков
## 🛠️ Технологии

- **Backend:** Django 4.2+
- **Database:** SQLite
- **Frontend:** HTML, CSS
- **Инструменты:** Git, Django Debug Toolbar

## 🎓 Освоенные технологии Django

### ✅ Основы фреймворка
- Архитектура MTV, маршрутизация URL, обработка запросов
- Динамические URL, система перенаправлений

### ✅ Работа с данными
- Модели Django со всеми типами связей (One-to-One, Many-to-One, Many-to-Many)
- ORM: сложные запросы, агрегации, оптимизация
- Миграции и управление базой данных

### ✅ Пользовательский интерфейс
- Шаблоны с наследованием, пользовательские теги и фильтры
- Формы с валидацией, загрузка файлов
- Статические файлы и медиа

### ✅ Администрирование
- Кастомизированная админ-панель с поиском и фильтрацией
- Групповые действия, настройка отображения

### ✅ Архитектура
- Классовые представления (ListView, DetailView, CreateView, UpdateView)
- Пагинация, миксины, переиспользование кода
